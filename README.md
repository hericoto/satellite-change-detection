
# Satellite Change Detection

## Описание проекта

Проект посвящён обнаружению изменений
зданий на спутниковых снимках,
полученных в разные даты.

## Цель

Разработка модели глубокого обучения
для сегментации изменений на спутниковых
изображениях.

## Датасет

LEVIR-CD:
https://justchenhao.github.io/LEVIR/

637 пар изображений.
Разрешение: 1024x1024.
Пространственное разрешение: 0.5 м/пиксель.

## Используемые технологии

- Python
- PyTorch
- OpenCV
- NumPy
- Matplotlib
- Siamese U-Net

Для решения задачи реализована нейросетевая архитектура Siamese U-Net. Она принимает два изображения одной территории, извлекает признаки, сравнивает их и формирует бинарную маску изменений.

## Структура проекта

- data/ - подготовка данных
- src/ - исходный код
- configs/ - конфигурации
- outputs/ - метрики и графики
- results/ - примеры предсказаний
- weights/ - веса модели

## Подготовка данных
Исходные изображения нарезаются на фрагменты размером 256 × 256 пикселей. Для каждой пары изображений формируется 8 фрагментов с координатами, заданными в скрипте prepare_data.py.

Всего подготовлено 5096 пар фрагментов:
- Обучающая выборка — 3560.
- Валидационная выборка — 512.
- Тестовая выборка — 1024.
```bash
python src/prepare_data.py
```

## Обучение
Обучение проводилось в течение 20 эпох с использованием:
- Оптимизатора Adam.
- Скорости обучения 0.001.
- Размерности пакета 8.
- Функции потерь BCEWithLogitsLoss в сочетании с Dice Loss.

Для итоговой оценки использовалась модель с наименьшим значением ошибки на валидационной выборке.
```bash
python src/train.py
```

## Оценка
Для оценки результатов используются метрики Precision, Recall, F1-score, IoU и Accuracy. Метрики рассчитываются по пикселям всей тестовой выборки.
```bash
python src/evaluate.py
```

## Ограничения

Модель выполняет бинарное обнаружение изменений. Она выделяет изменившиеся области, но не определяет характер изменения - появление или исчезновение объекта.

При подготовке данных используется фиксированный набор из восьми координат для извлечения фрагментов, поэтому исходное изображение покрывается неравномерно.
